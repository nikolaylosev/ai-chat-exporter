AI との会話を、含まれるすべてのファイルごと自分のパソコンに保存できます。Claude・Gemini・Grok・ChatGPT のチャットは Markdown ノートになり、各チャットのファイルは元の形式のままノートの隣に保存されます。

選ばれる理由
• テキストだけでなくすべてのファイル：アップロードしたファイル、モデルが作成したドキュメントやコード、Claude のアーティファクト、ChatGPT のキャンバス、生成画像をそのまま保存。
• Claude・ChatGPT・Grok のプロジェクトを指示・ファイル・チャットごと、Gemini のノートブックをチャットごと保存。
• Claude・Gemini・ChatGPT に加えて Grok にも対応。
• 数百件のチャットをまとめてバックグラウンドで保存し、保存済みのものはスキップ。
• アカウント不要、サーバーなし、トラッキングなし。無料でオープンソース。

コピーを残す理由
• チャットは削除されたり、アカウントとともに失われたり、プラン変更で見られなくなることがあります。
• 各サービスをスクロールする代わりに、ふだん使うノートアプリでファイルと一緒に検索・再利用できます。
• サービス間で履歴を移したり、古いチャットを整理する前にバックアップしたりできます。

ノートの内容
• 会話全体を YAML プロパティ（タイトル、日付、モデル、プロジェクト）付きの Markdown で保存。Obsidian の保管庫やほかのノートアプリにそのまま使えます。
• 思考過程・Web 検索・ツール呼び出しは折りたたみブロックで、必要ならチャットの別ブランチも保存。

使い方
• 開いているチャット：アイコンをクリックして「Save this chat」、または Alt+Shift+S（Mac は Option+Shift+S）。「Copy」を押すと Markdown としてクリップボードにコピーします。
• 多数のチャットやプロジェクト：エクスポートページを開き、日付・プロジェクト・タイトルで絞り込んで必要なもの（またはすべて）を選び、保存します。バックグラウンドで実行され、キャンセルもでき、失敗した項目のレポートを作成します。
• 保存先はダウンロードフォルダ、任意のフォルダ、または 1 つの .zip。ファイルを含めるかどうかも選べます。

プライバシー
• すべてはあなたのパソコンの中に残ります。拡張機能にはサーバーがなく、会話をどこにも送信しません。
• 各サービスにログイン済みのセッションを通じて、そのサービス自身の Web ページと同じ方法でチャットを読み込みます。パスワードやアクセストークンは保存しません。
